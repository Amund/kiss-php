Reference

Twig functions

path(name, params)

Generates URLs between routes :

{{ path('about') }}                          → /about
{{ path('blog', {slug: 'hello'}) }}          → /hello.html
{{ path('blog') }}                            → /blog
{{ path('blog', {page: 2}) }}                 → /blog/page/2

Trailing /index.html is automatically cleaned :

{{ path('index') }}                           → /
{{ path('blog') }}                            → /blog

route(name)

Access another route's resolved data :

{% set blog = route('blog') %}
<h1>{{ blog.title }}</h1>
{% for post in blog.items %}
  <a href="{{ path('blog', {slug: post.slug}) }}">{{ post.title }}</a>
{% endfor %}

asset(path)

Signed URLs with CRC32C hash for cache busting :

<link rel="stylesheet" href="{{ asset('css/style.css') }}">
<!-- → /css/style.css?v=70a5a1d3 -->

dump(...)

VarDump helper (only in debug mode) :

{{ dump() }}
{{ dump(foo, bar) }}

Twig filters

markdown

Converts Markdown to HTML via league/commonmark (GFM) :

{{ content|markdown|raw }}

Data sources

Files in data/ are loaded automatically and accessible via {{ global.* }}.

Supported formats : YAML, JSON, PHP, XML, INI, Markdown.

data/site.yml :

name: My Site
tagline: Great static site

{
  "name": "My Site",
  "tagline": "Great static site"
}

<?php
return [
  'name' => 'My Site',
  'tagline' => 'Great static site',
];
<?xml version="1.0"?>
<root>
  <name>My Site</name>
  <tagline>Great static site</tagline>
</root>
name = My Site
tagline = Great static site

Markdown

---
title: My Article
date: 2024-01-01
---
Content **markdown** here.

Frontmatter fields are available directly, body as content :

<h1>{{ title }}</h1>
<div>{{ content|markdown|raw }}</div>

CLI commands

Command Description
kiss init [dir] Create a new site
kiss build Build the whole site
kiss watch Build then watch for changes
kiss route [list|name] List or rebuild routes
kiss copy [path] Sync a file from copy/ to web/
kiss reset [all|dist|cache] Remove web/ and/or tmp/
kiss test Validate configuration
