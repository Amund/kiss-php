What is Kiss?

Kiss is a PHP static site generator. It uses Twig for templating, supports YAML/JSON/PHP/XML/INI data sources, dynamic page parameters, static file sync, and a watch mode with partial rebuilds.

Quick start

composer global require amund/kiss-php
kiss init my-site
cd my-site
kiss build

Features

  • items - dedicated property for child pages
  • path() - URL generation between routes
  • route() - cross-route data access
  • asset() - signed URLs (cache busting)
  • paginate - automatic pagination
  • Partial rebuilds - only impacted routes on file change

Workflow

graph TD
    A[kiss.yml] --> B[Config]
    B --> C[Build]
    C --> D[copy dir]
    D --> I[Static files]
    C --> E[route dir]
    E --> F[items + data]
    F --> G[Twig render]
    G --> H[HTML pages]
    H --> J[Route manifest]
    J --> K[Clean stale files]
